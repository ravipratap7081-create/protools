Hindi me samjho

CWC 2026 ke form me chaar cheezein upload karni hain — photo, signature, left thumb aur handwritten declaration — aur har ek ka size fix hai. Iske alawa form bharte waqt aapki live photo bhi capture hogi. Ye tool aapki chaaro files ko notice ke size-band me laata hai — poora kaam aapke browser me hota hai, file kahin upload nahi hoti. Thumb aur declaration ke liye notice me 200 DPI likha hai — is tool ki output file me 200 DPI metadata isliye likha jata hai kyunki uske pixels notice ke 200-DPI size se bilkul match karte hain (240×240 for 3 cm, 800×400 for 10 cm). Photo aur signature ke liye notice me koi DPI requirement nahi hai, isliye unme koi DPI claim nahi kiya jata. File taiyaar hone ke baad bhi portal par jaakar latest instructions zaroor check karein, kyunki form bharte waqt wahi final hote hain.

Step-by-step kaise karein?

  1. Photo chuno: JPG ya PNG select karo — photo 200×230 ke aspect me aayegi, target size chuno (default 35 KB), preview dekho, download karo
  2. Signature chuno: black ink wali signature select karo — greyish paper ho to "white background saaf karo" tick rakho, preview dekho, download karo
  3. Thumb chuno: white paper par black/blue ink se laga left thumb select karo — 240×240, 200 DPI output milega, preview dekho, download karo
  4. Declaration chuno: upar diya hua text apne haath se English me likhkar scan karo — 800×400, 200 DPI output milega, preview dekho, download karo
  5. Form bharte waqt live photo capture karna mat bhoolna — scanned photo uski jagah nahi le sakta
  6. Upload karne se pehle har file ka Technical PASS + Candidate check padho

Limitations — imaandari se

  • Ye tool sirf technical check karta hai — format, size, pixels aur (thumb/declaration ke liye) 200 DPI notice ke limits ke andar hai ya nahi. Acceptance ki guarantee nahi deta.
  • Photo ko preferred aspect (200:230) me center-crop kiya jata hai — chehra beech me rakhein, warna side cut sakta hai. Portal ke upload editor me bhi final crop kar sakte hain.
  • Agar preferred size par KB floor reach nahi hota (jaise saaf signature 140×60 par 10 KB se kam rehti hai), to tool 1.5×/2×/3× bada size deta hai — actual dimensions result me dikhaye jate hain. Portal ke liye preferred size mandatory nahi hai; bada size bhi accept hota hai. Aise fallback output par koi DPI claim nahi likha jata.
  • 200 DPI sirf thumb aur declaration ke liye likha jata hai — aur sirf tab jab pixels notice ke 200-DPI size se match karte hain. Pixels kam hon to file FAIL dikhayegi, DPI ka jhootha claim nahi likha jata.
  • Signature ki white-background cleanup sirf halke paper ko safed karti hai — signature ke strokes ko chhedti nahi, aur unhe distort bhi nahi karti.
  • Thumb ya declaration smudged/unclear ho to application reject ho sakti hai — upload karne se pehle preview me saaf dikhna zaroori hai.
  • Size har notification me alag ho sakta hai — apply karne se pehle Advt CWC/I-Manpower/DR/Rectt/2026/01 aur portal ke latest instructions check karein.
  • File browser me process hoti hai — upload nahi hoti.
