📋 PDF Compressor — Complete Guide

Ye tool kya karta hai?

PDF ke andar ki JPEG images ko dobara encode karta hai (quality aur size target ke hisab se), metadata hatata hai aur file structure optimize karta hai — jisse PDF chhota ho jata hai.

Step-by-step

  1. PDF select karo: "PDF Select Karo" button dabao
  2. Target chuno: 100 KB, 200 KB, 500 KB ya 1 MB
  3. Automatic compress: Tool quality dhoondh kar size target ke paas layega
  4. Download: "Compressed PDF Download Karo" button dabao

Limitations — imaandari se

  • Scanned ya photo wali PDFs sabse zyada chhoti hoti hain — sirf text wali PDF me kam farak padega.
  • Sirf JPEG (DCT) images re-encode hoti hain — baaki images aur text untouched rehte hain, text selectable rehta hai.
  • Bahut chhota target matlab kam quality — 100 KB target par photo wali PDF ki quality dikhne layak kam ho sakti hai.
  • Password-protected PDF pehle unlock karni padegi.
