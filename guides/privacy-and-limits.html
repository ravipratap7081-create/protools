Privacy aur limitations, imaandari se

Aapki files kahan jaati hain?

Jab aap yahan file drop karte hain, to wo aapke apne browser tab me JavaScript se read hoti hai. Wo hamare server par nahi bheji jaati, kisi account me store nahi hoti, aur tab band karte hi clear ho jati hai. Download links ke temporary blobs bhi tab band hote hi revoke ho jate hain.

Kya store hota hai: sirf anonymous usage counts (kaunsa page khula, kaunsa tool chala) — aur wo bhi sirf tab jab aapne consent banner par Accept dabayi ho. File ke naam ya content kabhi nahi bheje jate.

Trade-off kya hai?

Privacy ka ek trade-off hai: kaam aapke device ki memory use karta hai, isliye bahut badi files (lagbhag 100 MB se zyada total) purane phone par slow ho sakti hain. Aisa ho to laptop use karo, ya kaam ko chhote batches me todo. 50 MB se badi single PDF aur 30 MB se badi photo ko tool pehle hi rok deta hai taaki tab crash na ho.

Ye tool kya nahi karta

  • PDF ke andar ka text edit nahi karta.
  • Scanned image ko searchable text (OCR) nahi banata.
  • Password-protected PDF ko unlock nahi karta — pehle unlock karo, phir tool use karo.
  • Photo ke pixels crop nahi karta — sirf file size kam karta hai.

Problem aaye to

  • File load nahi ho rahi: password-protected ya damaged ho sakti hai. Pehle kisi aur viewer me kholkar check karo.
  • Merge me pages galat order me: Merge dabane se pehle ↑ ↓ se order set karo.
  • Phone slow ho raha hai: device memory ki limit hai, tool kharab nahi hai. Chhote batches ya laptop try karo.
  • Downloaded file nahi khul rahi: ek baar dobara download karo, aur check karo ki .pdf file khol rahe hain.
