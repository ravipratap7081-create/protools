How to split a PDF by pages

Splitting breaks one PDF into smaller PDFs. The trick is picking the right split mode — most people only need one of the three, and picking the wrong one creates extra files to clean up later.

The three modes, and when to use each

1. Extract specific pages

Choose this when you need only some pages: pages 1–3 and 5 of a 40-page report, for example. You type the ranges (like 1-3, 5, 8-10) and get one file containing exactly those pages, in that order. This is the right mode for form attachments, where only a certificate page or a mark-sheet page is asked for.

2. Split every N pages

Choose this when a long file must be broken into equal chunks: a 60-page book split every 10 pages, or a scanned bundle split into one file per applicant. You get several files, each with N pages except possibly the last one.

3. All single pages

Choose this when every page must stand alone — for example, sharing individual pages with different people, or uploading pages one by one to a portal. You get one file per page, delivered as a ZIP, because downloading 60 separate files one by one is painful.

Step by step

  1. Open the PDF Split tool and drop one PDF file in.
  2. Pick a mode: Extract, Every N pages, or All single pages.
  3. For Extract, type your page ranges carefully. Page numbers start at 1, and the first page of the PDF is page 1 — not page 0, and not the printed page number if the document has a cover or roman numerals.
  4. Click Split, download the result, and open it to confirm the right pages came out.

What splitting does not do

  • It does not edit or retype content. A page comes out exactly as it was, including any scan skew or faint print.
  • It does not remove a password. Unlock the PDF first.
  • It does not, by itself, make a file much smaller — unless the pages you drop were the heavy ones. For size reduction, read how to make a PDF smaller.

Common mistakes

  • Off-by-one ranges: typing 2-4 when you meant 1-3. Count from the PDF's first page, and verify the downloaded file.
  • Printed numbers vs PDF numbers: a book whose printed page 1 is the PDF's page 5 will mislead you. Use the PDF viewer's page count, not the printed footer.
  • Forgetting the ZIP: the all-pages mode downloads a ZIP. On a phone, open it with a file manager or a ZIP app before uploading pages anywhere.
