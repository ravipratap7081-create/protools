UP TGT 2026 ke form me aapki photo, signature aur certificates ki file ka size fix hai. Photo aur signature 10 se 100 KB ke beech hone chahiye, aur certificates ki PDF 20 se 200 KB ke beech. Limitations — imaandari se

  • Ye tool sirf technical check karta hai — format aur size notice ke limits ke andar hai ya nahi. Acceptance ki guarantee nahi deta.
  • PDF 20 KB se kam ho to use bina junk data ke bada nahi kiya ja sakta — aisi file FAIL dikhayegi. Dobara scan karke bada, saaf PDF banayein.
  • Image-heavy scanned PDF par size me bada farak nahi aayega — metadata hatane se hi farak padta hai.
  • Signature ki white-background cleanup sirf halke paper ko safed karti hai — signature ke strokes ko chhedti nahi, aur unhe distort bhi nahi karti.
